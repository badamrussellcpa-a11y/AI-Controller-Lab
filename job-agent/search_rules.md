# Job Scout – Search Rules

## Priority Order

1. Controller
2. Assistant Controller
3. Accounting Manager
4. Senior Accountant
5. Finance Manager (only if accounting leadership responsibilities)

## Scoring Guide

| Signal | Points |
|--------|-------:|
| Month-end close | +10 |
| General ledger ownership | +10 |
| Financial reporting | +9 |
| Balance sheet reconciliations | +9 |
| Journal entries | +8 |
| Audit support | +8 |
| Fixed assets | +7 |
| Intercompany | +7 |
| ERP systems | +6 |
| Team leadership | +5 |

## Automatic Reject

- Auto finance
- Consumer lending
- Mortgage
- Loan officer
- Insurance sales
- Collections-heavy roles
