## Level 3 — Code Literacy

From the actual title patterns:

```python
("Assistant Controller", r"\bassistant (?:corporate )?controller\b")
```

This pair holds a family name and a regular expression. r marks a raw string.
The backslash-b pattern means a word boundary; the optional parenthesized group
allows “Assistant Corporate Controller.” Patterns recognize text; they do not
understand Adam's career or prove suitability.

The role classifier returns a small structured result:

```python
return role, "CLEAR MATCH", f"Primary role family: {role}"
```

def defines a function; return gives values back. The f-string inserts the known
family into an explanation. Adjacent families use REVIEW NEEDED. if branches
choose among cases; a later return handles the fallback (no elif/else is necessary).

The actual within-employer sorting key includes:

```python
j["review_status"] != "CLEAR MATCH", PRIORITY[j["role"]],
j["title"].casefold(), j["id"]
```

Keys are compared left to right. False sorts before True, so CLEAR MATCH comes
first; family order then title and ID make ties predictable. The enclosing key
starts with employer name and canonical ID. Notice what is absent: coverage
and salary. Neither can hide or reorder a role.

The main pipeline collects unhandled IDs:

```python
fresh_ids = [j["id"] for j in selected if j["application_status"] in FRESH_STATES
             and j["location_classification"] != "INCOMPATIBLE"]
```

This list comprehension creates a separate list; it does not remove handled jobs
from selected. Dictionaries carry job fields; lists hold populations. The for
loop visits each record and if applies a condition.
